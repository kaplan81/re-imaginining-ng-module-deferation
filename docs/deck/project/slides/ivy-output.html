class BeanGridComponent {

  items = input.required(); // your code, unchanged

  stockState(bean) { return bean.stockKg < 60 ? "low" : … } // unchanged

 

  static ɵfac = (t) => new (t || BeanGridComponent)(); // added

  static ɵcmp = ɵɵdefineComponent({ // added

    selectors: [["cat-bean-grid"]], inputs: { items: [1, "items"] },

    template: function (rf, ctx) {

      1 & rf && ( ɵɵdomElementStart(0, "ul", 0), ɵɵrepeaterCreate(1, …), ɵɵdomElementEnd() );

      2 & rf && ( ɵɵadvance(), ɵɵrepeater(ctx.items()) );

    }

  });

}

1 & rf — create. Runs once. Builds the DOM.

2 & rf — update. Runs on every change detection.

Here is the same component, pulled out of the production bundle of the repository we are going to run later. Nothing is simplified except the parts I replaced with an ellipsis. Start at the top, because the top is the surprising part. Your class is still your class. The field is still a field. stockState is still an ordinary method, with the same ternary you wrote. If you pasted that class into the TypeScript playground with the decorator removed, you would get almost exactly these lines. The compiler did not touch your code. What it did was add two static properties, and delete the decorator. The first one, ɵfac, is the factory — how to construct this class, and what to inject when you do. The second is ɵcmp, and this is where everything from the decorator went. The selector is here. The inputs are here. And the template — the HTML file, the one sitting next to the component — has become a function. Two arguments. rf and ctx. rf is a bitmask, and the function has two halves. One runs when the view is created and builds the DOM. The other runs on every change detection pass and updates it. The whole of Angular's rendering model is in those two lines: build once, update many times. You do not need to read the instructions. What matters is the shape of what you are looking at — because this is plain JavaScript. Function calls and object literals. No decorator, no HTML, no SCSS, no Angular syntax of any kind. Every bundler on earth can read this. The template syntax, the decorator, the separate files — all of that is for us. By the time it ships, it is a function.
