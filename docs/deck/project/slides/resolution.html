All of this has a name. It is called module resolution, and it is one job: take a specifier, and work out which file it means. What is worth knowing is that the job can happen at three completely different moments, and that the choice between them changes a great deal about how an application is built and shipped. The bundler can do it, before anything ships at all. The browser's own loader can do it, by itself, as the page loads. Or a loader you shipped with the application can do it, while that application is already running. Three moments. One at a time. [Name the concept, read the three rows, move on.
