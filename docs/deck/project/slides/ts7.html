The APIs Angular needs are gone

“The Angular compiler implements its own code transformations via the ts.Transformer API which is not available cross-language.”

Angular blog · An update on Angular’s TypeScript 7-powered Compiler · September 2026

1

TypeScript 7’s compiler is a program written in Go.

2

ts.Transformer is only possible while both sides are JavaScript.

3

Go and JavaScript cannot share objects. So those APIs cannot be made public again

And then this happened. TypeScript 7 shipped in July. Same language, same type system, but the compiler itself has been rewritten in Go, and it is roughly ten times faster. Here is the Angular team's own sentence about what that costs them. The Angular compiler implements its own code transformations via the ts dot Transformer API, which is not available cross-language. Three steps to see why, and they are worth taking slowly. One. The new TypeScript compiler is a Go program. Not JavaScript that got faster — a different language, compiled to a binary. Two. ts.Transformer is not a file format and it is not a protocol. It is TypeScript calling a JavaScript function that Angular supplies, handing it a live object — the syntax tree — letting Angular rearrange that object in place, and then carrying on with the result. Both sides are JavaScript. Both sides are in the same process. They are pointing at the same objects in the same memory. Three. Go and JavaScript cannot do that. You can send data between them — text, JSON, bytes down a pipe. What you cannot do is hand a Go program a JavaScript function and have it call you back with a live tree. So this is not an API that got harder to use, or changed shape, or needs a wrapper written for it. A set of APIs that used to be public simply cannot be public any more, because there is no way to express them across two languages. Angular will use TypeScript 7's interop for type-checking and diagnostics, where sending data is enough. For compilation and transformation, sending data is not enough. Which means the capabilities TypeScript used to provide, Angular now has to provide itself. [Read the quote aloud, then count the three points on your fingers. Point two is the one that does the work.]
