A web standard, available in every major browser since 2023.

Second moment. This one is a browser feature, and a surprising number of people have never seen it. It is a script tag, with a type of importmap, and inside it a piece of JSON. The JSON says: when any module asks for at-angular-slash-core, fetch this file instead. When anything asks for rxjs, fetch that one. That is the whole mechanism. There is no library here. Nothing was installed. This is the browser's own module loader doing the lookup, using a table it was handed. Two things are worth knowing about it. The first is timing, and it is strict. The map has to be in the document before the first module import runs. Not shortly after. Before. Which is why applications that rely on it split their startup into two files — one tiny script that installs the map, and then a second one that actually starts the application. The second is that it is not new and it is not experimental. Import maps are a web standard and they have worked in every major browser since 2023. No polyfill, no bundler plugin, no runtime. So here a bare specifier does reach the browser, and the browser can resolve it — because somebody handed it the answers in advance. [Read the JSON out — it is three lines and it explains itself. Then the timing rule, which is the part people get wrong.]
