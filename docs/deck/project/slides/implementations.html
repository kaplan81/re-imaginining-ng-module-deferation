That model has been implemented twice, and these two are what the rest of the talk compares. The first keeps the name. Module Federation, the packages under at-module-federation, the one that started in webpack and now runs on Rspack and on Vite as well. The second is Native Federation, from the Angular Architects team — the same model rebuilt on web standards instead of on a bundler's internals. Three rows, and the first one causes the other two. Who resolves. Both of them have a loader — the difference is whose. Module Federation ships one with your application, and it reads from a structure it keeps in memory called the share scope. Native Federation uses the loader the browser already has, and that one reads from an import map. The paths. Module Federation never writes them down anywhere, so the code is asked again every single time something is needed. Native Federation negotiates everything at boot, writes the result into the import map, publishes it, and from then on the browser handles every lookup. And the last row is where it bites. Module Federation can be told to override a remote it has already registered — registerRemotes, with force. Be precise about what that does, because the name invites the wrong picture: it does not edit a path. It finds the registration by name, tears the old one out, and pushes an entirely new one in its place. The library warns you while it does it — the remote is already registered, and overriding it may cause unexpected errors. Native Federation cannot do that, and the reason is not that somebody forgot to write the function. It is the web platform itself. Add a second import map to a page that already has one and the browser accepts it quite happily — new names work. But give it a name the first map already defined, and the new value is silently ignored. No error, no warning. The first mapping wins, for the lifetime of that page. So once the map is published, those paths are final. Not by choice. The simplest way to hold all of it: one of them writes the answer on a note and pins it to the door, and from then on everyone reads the note. The other keeps a librarian, and you ask her every time.
