A custom pipeline is a config file and a plugin. The plugin catches every .ts before the bundler reads it, runs the Angular compiler, hands back the result.

So the bundler is becoming a choice. Except that it already is one, and has been for a while. The previous slide said that a bundler can only build Angular by hosting the Angular compiler inside itself, as a plugin. That sounds like a reason nobody would bother. People bothered. Read this table left to right, because that is the order the decision happens in. You pick a pipeline. The pipeline loads an Angular plugin. The plugin determines which bundler ends up doing the bundling. The top row is the one everybody has. A file called angular dot json, the command ng build, the plugin at-angular-slash-build, and esbuild underneath. Most people have never needed to know the last two are there. The other two rows are custom pipelines, and that phrase is doing real work. There is no angular dot json involved and the ng command never runs. The second row is a file called rspack dot config dot ts and the command rspack build, which loads a plugin from Nx, and lands on Rspack. The third is vite dot config dot ts and vite build, which loads the plugin from the Analog project, and lands on Rolldown. That third one is worth one word of precision. Vite is not a bundler — it is a build tool. The bundler underneath it is Rolldown. Which is why the third column says Rolldown and not Vite. So how does any of this actually work? All three plugins do the same job, through three different plugin APIs. Each registers with its bundler and says: before you read a TypeScript file, hand it to me first. The plugin runs the Angular compiler on it and gives back the result. esbuild calls that hook onLoad. Vite calls it transform. Rspack does it through a plugin of its own. That is what hosting the compiler means, concretely. The Angular compiler never runs on its own here. It runs as a function the bundler calls, in the middle of the bundler's own work. Which also tells you why there has to be one of these per bundler. The compiler is the same every time. The hook is not. [Walk the first row, then say "the other two are custom pipelines". The left-to-right order is the whole slide.]
